# VedaNeri.org revamp

| Folder            | What                                          | Port |
|-------------------|-----------------------------------------------|------|
| `apps/web`        | Public website, Next.js, EN + TA              | 3000 |
| `apps/cms`        | CMS portal for ashram staff, Vite + React     | 3001 |
| `apps/api`        | REST API, Node.js + Express + MySQL           | 4000 |
| `services/worker` | Python: WhatsApp, media jobs, AI              | 8000 |
| `database`        | SQL migrations (run in file order)            |      |
| `infra`           | docker-compose (MySQL), nginx                 |      |

## Run it

```
npm run db:up        # start MySQL in Docker (or point .env at your own MySQL)
npm run db:migrate   # create tables
npm run db:seed      # create the first CMS admin (see SEED_ADMIN_* in .env)
npm run dev          # api + web + cms together
npm run dev:worker   # Python worker (separate terminal)
```

Health check: http://localhost:4000/api/v1/health
Website: http://localhost:3000   CMS: http://localhost:3001

Secrets live in `.env` (generated by the setup script, never committed).
